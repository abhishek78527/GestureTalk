# GestureTalk

GestureTalk is a Streamlit app that converts hand-sign letters into sentences using MediaPipe, a keypoint-based classifier, and LLM APIs (Gemini / Hugging Face). The app also offers text-to-speech output.

## Quick start (for developers)
1. Clone the repo.
2. Create a Python virtual environment and install dependencies.
3. Add your API keys (see `secrets` section).
4. Run `streamlit run app.py`
